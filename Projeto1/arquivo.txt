2.
O SoC BCM2837B0, usado na Raspberry Pi 3 Model B+, apresenta a CPU Cortex-A53 (low-power), que implementa a arquitetura Armv8-A 64-bit em 4 cores a 1.4GHz. Cada core possui uma memória cache L1 (até 64Kb, a depender da configuração), sendo a L2 (até 2Mb) compartilhada. A interface serial apresenta suporte para SPI, SSP e LoSSI. Apresenta também interface para protocolos UART e mini UART. Por fim, a GPU é a Video Core IV, com suporte para 720p, 400MHz, OpenGL-ES 1.1/2.0 e 4x multisample antialiasing. 
O Soc BCM2711, por sua vez, possui CPU Cortex-A72, de mesma arquitetura 64-bit, com um a quatro cores por processador, a 1.5GHz *. Possui distribuição semelhante das memórias caches L1 (48Kb instruction cache e 32Kb data cache) e L2 (até 4Mb). Possui suporte e interface para protocolos SPI, SSP, LoSSI. Possui também 1 mini UART e 5 PL011 UARTs. A GPU é a Video Core IV, rodando até 500MHz, com suporte para H.265(4K60p decode) e H.264(1080p60 decode, 1080p60 encode), OpenGL-ES 3.0.
Por fim, o BCM2712, usado na Raspberry Pi 5 possui CPU Cortex-A76, com implementação da mesma arquitetura 64-bit (com suporte para ISAs A64, A32 e T32), com destaque para o suporte para instruções de produto escalar (dot product). Memória cache L1 (64Kb para instruções e 64Kb para dados) individual e memória L2 (512Kb por core)com protocolo de coerência MESI. A referência [2] menciona a presença de uma L3 de 2Mb. Continua possuindo interface para os protocolos de comunicação serial. GPU VideoCore VII, com 960MHz e suporte para OpenGL ES 3.1
